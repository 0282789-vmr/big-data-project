# Diccionario de Datos — UrbanFlow

Este documento describe los principales campos utilizados en la capa analítica de UrbanFlow.

## Campos principales

| Campo | Descripción |
|---|---|
| pickup_datetime | Fecha y hora de inicio del viaje |
| dropoff_datetime | Fecha y hora de finalización del viaje |
| PULocationID | Identificador de la zona de pickup |
| DOLocationID | Identificador de la zona de dropoff |
| trip_miles | Distancia del viaje en millas |
| trip_time | Duración del viaje en segundos |
| base_passenger_fare | Tarifa base pagada por el pasajero |
| driver_pay | Pago al conductor |
| year | Año del viaje |
| month | Mes del viaje |
| day_of_week | Día de la semana |
| pickup_hour | Hora de pickup |
| trip_duration_minutes | Duración del viaje en minutos |
| wait_time_minutes | Tiempo de espera en minutos |
| revenue_per_mile | Ingreso por milla |
| revenue_per_minute | Ingreso por minuto |
| avg_speed_mph | Velocidad promedio en millas por hora |
| driver_pay_ratio | Relación entre pago al conductor y tarifa base |
