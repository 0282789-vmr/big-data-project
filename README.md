# UrbanFlow

Plataforma de Inteligencia de Movilidad con Big Data

## Pregunta de negocio

¿Cómo puede un operador de movilidad utilizar millones de viajes históricos para determinar dónde y cuándo posicionar capacidad para maximizar la utilización y los ingresos?

## Dataset

Registros de viajes High Volume For-Hire Vehicle (HVFHV) de NYC TLC.

- Periodo: septiembre de 2023 – julio de 2026
- Tamaño RAW: ~16.05 GB
- Archivos Parquet: 35
- Registros RAW: 710,576,363
- Registros CURATED: 710,451,024

## Tecnologías utilizadas

- Google Cloud Storage
- Google Cloud Dataproc
- PySpark
- BigQuery
- Looker Studio
